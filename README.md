# ghanaian-cuisine-yoloV8
# 🍲 Regional Ghanaian Cuisine Detection System (YOLOv8)

A localized AI solution developed at **KNUST** to bridge the gap in food recognition technology for regional Ghanaian dishes.

## 📊 Dataset Overview
*   **Total Images:** 852+
*   **Composition:** Hybrid dataset featuring 800+ original high-fidelity images and integrated data from Hugging Face and Roboflow.
*   **Target Classes:** Focused on regional staples (Banku, Fufu, Jollof, etc.).
*   **Phase:** Mannual Annotation and Bounding Box Labeling.

## 🛠️ Tech Stack
*   **Architecture:** YOLOv8 Object Detection
*   **Mobile Frontend:** React Native(Planned integration.)
*   **Web Frontend:** React/Next.js(Planned for Post-Training deployment)
*   **Environment:** Python 3.10+
