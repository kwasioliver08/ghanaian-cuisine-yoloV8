# 📊 Dataset Specifications

## Overview
This repository utilizes a hybrid dataset of **852+ images** focused on regional Ghanaian cuisine.

## Data Composition
* **Original Collection:** 800+ high-fidelity images taken in local environments.
* **Integrated Data:** Supplemented with images from Hugging Face and Roboflow to improve model variety.

## Target Classes
The model is being trained to detect the following:
* **Banku**
* **Fufu**
* **Jollof Rice**
* **Plain Rice**
* **Waakye**
* **Boiled Plantain**
* **Boiled Yam**
* **Bread**
* **Beans(Gob3)**
* **Kenkey**
* **Kokonte**
* **Koko**
